<h1 align="center">SATEP</h1>

<p align="center">
<strong>Sistema de Agendamento de Transporte para Pacientes</strong>
</p>

<p align="center">
Aplicativo mobile desenvolvido em <strong>Flutter</strong> para facilitar o agendamento e a organização do transporte de pacientes para consultas médicas.
</p>

<p align="center">
O sistema busca digitalizar e otimizar o processo que atualmente é realizado de forma manual, tornando o gerenciamento <strong>mais eficiente, organizado e acessível</strong>.
</p>

<hr>

<h2>🎯 Objetivo</h2>

<p>
O objetivo do <strong>SATEP</strong> é oferecer uma solução tecnológica para melhorar a gestão do transporte de pacientes que precisam se deslocar para consultas, exames e tratamentos médicos.
</p>

<p>Com o aplicativo, será possível:</p>

<ul>
<li>Reduzir erros de agendamento</li>
<li>Melhorar a organização das viagens</li>
<li>Facilitar a comunicação entre pacientes e administração</li>
<li>Otimizar o controle de transporte</li>
</ul>

<hr>

<h2>🚀 Funcionalidades</h2>

<ul>
<li>📅 Agendamento de transporte</li>
<li>👤 Cadastro de pacientes</li>
<li>📍 Informações da consulta</li>
<li>📋 Visualização de viagens agendadas</li>
<li>🔎 Consulta de dados do paciente</li>
<li>📱 Interface mobile simples e acessível</li>
</ul>

<hr>

<h2>🛠 Tecnologias Utilizadas</h2>

<ul>
<li><strong>Flutter</strong> — Framework para desenvolvimento mobile</li>
<li><strong>Dart</strong> — Linguagem de programação utilizada pelo Flutter</li>
</ul>

<h2>⚙️ Como executar o projeto</h2>

<h3>1️⃣ Clonar o repositório</h3>

<pre>
git clone https://github.com/AbnerSantosAlves/SATEP.git
</pre>

<h3>2️⃣ Acessar a pasta do projeto</h3>

<pre>
cd SATEP
</pre>

<h3>3️⃣ Instalar dependências</h3>

<pre>
flutter pub get
</pre>

<h3>4️⃣ Executar o aplicativo</h3>

<pre>
flutter run
</pre>
